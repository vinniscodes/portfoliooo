# **App Name**: Curriculum Vitae: Coded Edition

## Core Features:

- Personal Bio: A brief introduction highlighting my skills, experience, and career goals, styled with CSS.
- Work Experience: Detailed list of previous jobs with responsibilities and achievements.
- Projects Showcase: Portfolio section to display completed projects with descriptions and links.
- Hangman Game: Interactive Hangman game implemented using JavaScript.
- Word Display: Show the masked word to be guessed, updating with correct guesses.
- Letter Input: Allow users to input letters, either via text input or a virtual keyboard.
- Game Logic and Management: Tracks attempts, displays used letters, and manages win/loss conditions.

## Style Guidelines:

- Primary color: Deep violet (#673AB7) to reflect creativity and intellect.
- Background color: Light gray (#F0F0F0) for a clean, professional look.
- Accent color: Vibrant magenta (#E91E63) for highlighting important information.
- Font: 'Inter' sans-serif font for both headings and body text, to ensure readability.
- Simple, professional icons to represent skills and technologies.
- Clean, modern layout with a focus on readability and ease of navigation.
- Subtle animations for transitions and interactive elements to enhance user experience.
